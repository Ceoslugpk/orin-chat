Orin Chat welcomes responsible security research. If you find a vulnerability in this project, report it privately so it can be investigated and fixed.

## Reporting a Vulnerability

We use Github to track the security issues that affect our project. If you believe you have found a vulnerability, please disclose it via this [form](https://github.com/Ceoslugpk/orin-chat/security/advisories/new). This will enable us to review the vulnerability, fix it promptly, and reward you for your efforts.

If you have questions about the process, use the private reporting form above.

Please describe a clear, realistic impact. Do not post vulnerability details in public issues or on social media; use the private reporting form so maintainers can respond safely.

> Submit vulnerability disclosures through [GitHub Security Advisories](https://github.com/Ceoslugpk/orin-chat/security/advisories/new).

## Vulnerabilities we care about 🫣
> Note: Do not test against third-party production services. Use an authorized self-hosted instance.
- Remote command execution
- SQL Injection
- Authentication bypass
- Privilege Escalation
- Cross-site scripting (XSS)
- Performing limited admin actions without authorization
- CSRF

Reports are reviewed by the project maintainers through GitHub Security Advisories.

## Non-Qualifying Vulnerabilities

We consider the following out of scope, though there may be exceptions.

- Missing HTTP security headers
- Incomplete/Missing SPF/DKIM
- Reports from automated tools or scanners
- Theoretical attacks without proof of exploitability
- Social engineering
- Reflected file download
- Physical attacks
- Weak SSL/TLS/SSH algorithms or protocols
- Attacks involving physical access to a user's device or a device or network that's already seriously compromised (e.g., man-in-the-middle).
- The user attacks themselves
- Incomplete/Missing SPF/DKIM
- Denial of Service attacks
- Brute force attacks
- DNSSEC

If you are unsure about the scope, please create a [report](https://github.com/Ceoslugpk/orin-chat/security/advisories/new).
